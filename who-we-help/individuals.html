{% include section-heading.html title="Things people ask us about" %}

“It's gotten so slow.”

Cleanups, updates, backups, and honest advice about whether a machine is worth keeping.

“Is this email a scam?”

Passwords, two-factor setup, and a plain checklist for spotting the fakes yourself.

“The wifi drops in the back room.”

Home internet, routers, printers, and TVs that finally talk to each other.

“Where did my photos go?”

Recovering files, organizing what's left, and setting up backup so it can't happen twice.
