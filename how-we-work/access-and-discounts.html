Closer to home

Incentives across Maine.

We do not bill travel time to clients elsewhere in Maine, and wherever we are working we set aside time for pro bono work in that community.

How we support Maine
{% include section-heading.html title="Pro bono and deep discounts" class="section-heading--sm section-heading--gap" %}

We hold back a limited number of pro bono and deeply discounted hours each quarter for work where we think we can make a real difference. If you have a project that would matter in your community and the cost is what is stopping it, send us a message and we will talk about it.
